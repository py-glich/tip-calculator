# 🍽️ Tip Calculator (a.k.a. “Who Pays What?”)

A simple but smart tip calculator that helps you split the bill without awkward math at the table 😄

Built using **HTML, CSS, and JavaScript** — no frameworks, no libraries, just pure frontend logic.

---

## ✨ What this app does

You enter your bill amount, choose a tip %, and add number of people.

The app instantly shows:

- 💸 Total tip amount  
- 🧾 Grand total (bill + tip)  
- 👥 Per person split  

Everything updates live as you type — no buttons needed.

---

## ⚡ Features

- 🔄 Live calculations (instant updates)
- ⚠️ Inline validation (clean error messages, no alerts)
- 🎯 Quick tip buttons (10%, 15%, 20%)
- ✍️ Custom tip input support
- 📱 Fully responsive design (mobile + desktop)
- 🔁 Reset button to start fresh

---

## 🧠 How it works

1. Enter bill amount (example: 2500)
2. Select or enter tip percentage
3. Enter number of people
4. App automatically calculates:

- Tip = bill × tip%
- Grand total = bill + tip
- Per person = grand total ÷ people
